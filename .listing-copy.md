## Glama / MCP directory

**Name:** DOMStrip

**Short description (≤ 60 chars):**
```
Clean Markdown from web pages for AI agents.
```

**Short description (≤ 100 chars, MCP Registry):**
```
Turn any web page or raw HTML into compact, clean Markdown for AI agents.
```

**Long description (~400 chars):**
```
DOMStrip converts a public URL or raw HTML into compact Markdown an AI agent
can actually read. Scripts, forms, embeds, trackers and hidden nodes are
removed; headings, fenced code blocks with language hints, and tables survive.

Two tools: fetch_clean_markdown (fetches a public http(s) URL) and clean_html
(converts HTML you already have, no network fetch for the HTML).

Fetches are validated at connect time on every redirect hop — loopback,
private, link-local, metadata and CGNAT addresses are refused. Each tool
call uses one idempotency key across its retries, so a transient failure
never bills twice.

Not suitable for pages that need JavaScript, a login, or bot challenges;
those return content_not_extractable.
```

**Categories / tags:** Developer Tools · Web · Search & Scraping · Data
**Transport:** stdio (local process)
**Runtime:** Python 3.12, `uvx domstrip-mcp`
**Repository:** https://github.com/xo0ps/DOMStrip-Client
**Homepage:** https://domstrip.dev
**Install:** `pip install domstrip-mcp` / `uv tool install domstrip-mcp`

**Known limitation to state plainly if asked:** no headless rendering; JS-heavy
pages fail by design in this version.
